# Face Recognition Attendance System

A Python-based desktop application that automates attendance management using face recognition technology.

## 💡 Overview

This project is a smart attendance system integrated with a GUI, leveraging real-time face recognition to mark attendance.
It is built using Python’s `Tkinter` for the interface and OpenCV for facial recognition.
It captures student images, trains on them, and marks attendance in a secure and efficient manner.

## 🚀 Features

- 🖥️ User-friendly GUI built with `Tkinter`
- 🔐 Password-protected student registration
- 📷 Real-time face detection and recognition using OpenCV (LBPH algorithm)
- 🗃️ Maintains attendance records in daily CSV files
- 📊 Live tabular display of attendance (ID, Name, Date, Time)
- 📂 Automatic directory creation and file management
- 📅 Date & Time stamping for every attendance entry


## 🛠️ Technologies Used

- **Python 3**
- **Tkinter** – GUI
- **OpenCV** – Face detection and recognition
- **NumPy & Pandas** – Data processing
- **CSV** – Data storage
- **PIL (Pillow)** – Image processing
